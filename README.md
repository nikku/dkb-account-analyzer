# DKB Account Analyzer

Account balance and spending analysis for your DKB account. Reads your account export (CSV). Privacy friendly: Works client-side, in the browser. Your data never leaves your machine.

[![Account analyzer app screenshot](./docs/screenshot.png)](https://nikku.github.io/dkb-account-analyzer/)

## Build and Run

```sh
# spin up development server
npm run dev

# execute all tests
npm test
```
